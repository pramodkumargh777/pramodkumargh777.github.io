01Context

Answers and automation grounded in enterprise knowledge.

The platform combines conversational assistance, knowledge retrieval over enterprise connectors such as SharePoint, and task-oriented agents for ITSM, knowledge and productivity workflows.

My focus is the backend: the services, data model and pipelines that make retrieval accurate and agents dependable — and the delivery work to run them in more than one enterprise environment.

02Architecture

Ingest carefully, retrieve precisely, route deliberately.

  • Backend: Python, FastAPI and PostgreSQL, with typed boundaries everywhere.
  • LLM routing layer with health probing, p95-latency-based routing and per-project budgets across Azure OpenAI deployments.
  • MCP server integration for agent tool-calling.
  • Async processing on Celery and Redis, with retries, circuit breakers and task claiming.
  • Delivery on Azure Container Apps with Docker and Azure DevOps CI/CD across Dev, Test and Production — including troubleshooting, tuning and observability.

03RAG quality

Retrieval quality is decided before the prompt.

  • Ingestion first. A configurable 7-stage framework with layout-aware extraction from PDFs and scans, so clean text reaches the index — across 10,000+ documents.
  • Hybrid retrieval. Vector and keyword search with reranking, tuned against real user queries rather than benchmarks.
  • Context order matters. Models use the start and end of a long context better than the middle, so retrieved chunks are ordered deliberately.
  • Evaluate like tests. Golden datasets and judge models are the unit tests of GenAI — changes to chunking, prompts or models should move a measured number.

04Agents & guardrails

Agents that are allowed to say “I don't know”.

  • 15+ LLM agents shipped for enterprise automation across ITSM, knowledge and productivity workflows.
  • Typed outputs. Structured prompts with outputs validated by Pydantic before anything downstream trusts them.
  • Bounded cost and latency. Model calls go through a routing layer that tracks each deployment's health, p95 latency and per-project budget.
  • Graceful failure. Confidence checks and explicit “I don't know” paths instead of confident guesses; retries and circuit breakers for the work around the model.
